`organize_research_history.py` برنامهٔ مهاجرت را ثبت و همان برنامه را اجرا کرده است.
اجرای عادی پروژه نیازی به تکرار آن ندارد. این ابزار قبل و بعد از جابه‌جایی بایت‌ها
را بررسی می‌کند؛ برای بررسی وضعیت فعلی از ابزار فقط‌خواندنی استفاده کنید:

```powershell
python -B scripts/audit_research_layout.py --require-artifacts
```

در clone بدون وزن‌ها، گزینهٔ `--require-artifacts` نبود فایل‌های محلی را خطا می‌گیرد؛
بدون آن نیز فهرست آرشیوهای مفقود صریح گزارش می‌شود. دادهٔ خارج از Git باید از
ZIPهای ثبت‌شده یا نسخهٔ پشتیبان واقعی بازیابی شود. این پوشه مجوز تغییر فایل تاریخی نیست.
