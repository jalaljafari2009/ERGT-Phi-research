# ADR-0008 — بازنگری بستهٔ M2-E003 پس از نبود قفل cohort در release

- تاریخ: ۲۲ سپتامبر ۲۰۲۶.
- وضعیت: **accepted برای اصلاح زیرساختی و ساخت v002**؛ فرضیه، داده و gateها ثابت‌اند.
- والد: [ADR-0007](ADR-0007.md).
- run: `M2-E003/v001/20260921T221000Z-m2e003-local`.

## مشاهده

اجرای package-bound نسخهٔ v001 پیش از بارگذاری مدل و پیش از تولید هر metric با
`FileNotFoundError` متوقف شد. سازندهٔ source package مسیر
`research/plans/M2_E003_FRESH_DEVELOPMENT_LOCK.json` را در ZIP نگذاشته بود، درحالی‌که
runner آن را لازم داشت. هیچ خروجی علمی یا artifact اجباری تولید نشد.

## تصمیم

v001 با review نوع `revise` حفظ می‌شود. v002 همان checkpointها، seedها، cohort hash،
پنجره‌ها، کنترل‌ها، آستانه‌ها و بودجه را نگه می‌دارد و فقط یک نسخهٔ byte-identical از
قفل cohort را کنار protocol خود قرار می‌دهد؛ command به همان مسیر بسته‌شونده اشاره
می‌کند. این تغییر فرصت تنظیم بر اساس نتیجه نمی‌سازد، چون هیچ نتیجه‌ای دیده نشده است.

معیار پذیرش اصلاح: source manifest باید فایل قفل را شامل شود، hash آن با v001 برابر
بماند و اجرای بسته از مرحلهٔ بررسی lock عبور کند. نتیجهٔ علمی v002 جدا import و review
می‌شود. M3 و پنل M8 همچنان بسته‌اند.
