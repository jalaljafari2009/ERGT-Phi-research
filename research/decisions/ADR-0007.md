# ADR-0007 — پذیرش تحویل checkpoint در M2-E002 و ورود به تأیید توسعهٔ تازه

- تاریخ: ۲۲ سپتامبر ۲۰۲۶.
- وضعیت: **accepted برای دامنهٔ گام اجرایی ۲**؛ پذیرش علمی M2 یا مجوز M3 نیست.
- تصمیم‌گیر/مجوز: ادامهٔ صریح پژوهشگر پس از آماده‌سازی release؛ تصمیم مطابق gateهای پیش‌ثبت‌شده گرفته شده است.
- والد: [ADR-0006](ADR-0006.md).
- هدف: GOAL-001 نسخهٔ ۲، مسیر A و M2.
- شاهد اصلی: `M2-E002/v001/20260921T210953Z-48abf488-local`.

## مسئله و شاهد

M2-E002 باید نشان می‌داد checkpoint نخستِ واجد دو پنجره واقعاً ذخیره، منجمد، در فرایند
تازه بارگذاری و از همان state ادامه‌پذیر است، درحالی‌که مدل مرجع تغییر نمی‌کند. release
قفل‌شده با SHA-256 برابر
`8bc4ef850b4fe02844d93aeea48b83fa44a966a4fe9537390bd202f831864ed7`
روی Windows/CPU و خارج از Colab اجرا و bundle آن با SHA-256 برابر
`f700ebff35b6b4b2d5b78adee3e6cfbf5f3e495bd715db3bd2456f50ec90ace0`
وارد شد.

هر ۱۹ gate پیش‌ثبت‌شده پاس شدند. checkpoint نخست در epoch 3 و step 72 انتخاب شد؛
balanced accuracy پایش `0.7555267392741171`، recall کلاس‌ها به‌ترتیب
`0.8202247191011236`، `0.7228260869565217` و `0.7235294117647059` و کنترل shuffled
برابر `0.3218691629069801` بود. hash checkpoint منتخب
`8056322cf7c58dd5845f87bf6a89ccbb2ddd76c2d06933a3b5f2fa533688a234`
است. reload، resume، freeze و برابری دقیق خروجی و تصمیم native نیز پاس شدند.

## تصمیم

اجرای واردشده برای دامنهٔ محدود گام اجرایی ۲ `pass` می‌شود و همین checkpoint ورودی
منجمد گام ۳ خواهد بود. گام ۳ باید پیش از مشاهدهٔ نتیجه، cohort توسعهٔ تازه و مستقل،
ممیزی برخورد raw text و counterfactual pair، دو پنجرهٔ ثابت، Q-only و کنترل بدون phase
با ظرفیت مشابه را ثبت کند.

این تصمیم بهبود پاسخ native، تعمیم مستقل، برتری phase بر Q یا تکمیل M2 را نتیجه
نمی‌گیرد. monitor از cohort آموزش M0 آمده و برای انتخاب checkpoint مصرف شده است. اجرای
ثبت‌شده محلی است و `colab_detected=false`؛ بنابراین فقط قابلیت حمل release و تحویل
checkpoint را ثابت می‌کند. دادهٔ نهایی M8 همچنان بسته می‌ماند و M3 مجاز نیست.

## گزینه‌ها و معیار بازنگری

رد کامل run با وجود پاس‌بودن همهٔ gateها، اطلاعات مهندسی معتبر را از بین می‌برد؛ پذیرش
کل M2 نیز استقلال داده و کنترل علّی را نادیده می‌گیرد. پذیرش دامنه‌ای انتخاب شد تا
handoff قابل استفاده باشد و ادعای علمی بزرگ‌تر باز بماند.

اگر ممیزی integrity بعدی ناسازگاری در bundle، checkpoint یا source lock پیدا کند، این
تصمیم بازنگری می‌شود. اگر تأیید تازه gateها را پاس نکند یا phase از کنترل‌های متناظر جدا
نشود، checkpoint به M3 منتقل نمی‌شود و نتیجهٔ منفی حفظ خواهد شد.

## اقدام بعد

ساخت و پیش‌ثبت `M2-E003/v001` برای تأیید frozen روی توسعهٔ تازه، اجرای release مستقل،
ورود bundle و داوری نتیجه. مسئول ساخت و ثبت: ایجنت؛ اجرای Colab در صورت نیاز: پژوهشگر.
