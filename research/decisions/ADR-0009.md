# ADR-0009 — انتقال byte-identical قفل M2-E003 به مسیر تضمین‌شدهٔ source package

- تاریخ: ۲۲ سپتامبر ۲۰۲۶.
- وضعیت: **accepted برای v003، فقط اصلاح بسته‌بندی**.
- والد: [ADR-0008](ADR-0008.md).

## مشاهده و تصمیم

preflight `source_manifest.json` نسخهٔ v002 نشان داد packager فایل lock کنار revision را
نیز وارد ZIP نمی‌کند. v002 اجرا نشد و هیچ metric تازه‌ای تولید نکرد. فایل قفل با همان
SHA-256 برابر `3bf9865f8a1edfedc50113251ef7175dcd28fe075b1502be5d9fce7e4a0b4adb`
به `configs/m2_e003_fresh_development_lock.json` کپی شد؛ `configs/` طبق سیاست packager
همیشه داخل source archive قرار می‌گیرد.

v003 فقط command و شمارهٔ revision را به این مسیر تغییر می‌دهد. checkpointها، seedها،
هویت ۵۰۴ مثال و ۲۵۲ جفت، پنجره‌ها، کنترل‌ها، آستانه‌ها و بودجه byte-for-byte یا
معنایی ثابت‌اند. پیش از اجرا باید حضور مسیر تازه و hash آن در `source_manifest.json`
کنترل شود. v002 یک release preflight نامعتبر است و اجرا نمی‌شود.
