# ADR-0003 — انتقال واقعی تاریخچه و جمع‌آوری اطلاعات گفتگو

- تاریخ: ۲۰۲۶-۰۹-۲۰؛ وضعیت: پذیرفته برای سامان‌دهی.
- مبنای اختیار: درخواست صریح پژوهشگر برای دسته‌بندی ریپو و گردآوری اطلاعات گفتگو.
- والد: [ADR-0001](ADR-0001.md) و [ADR-0002](ADR-0002.md).

## مسئله

چرخهٔ جدید برای آزمایش‌های بعدی آماده بود، اما گزارش‌ها، manifestها، نتایج خام،
نسخه‌های قبلی و متن‌های دریافت‌شده همچنان در چند مسیر یا فقط در گفتگو قرار داشتند.
README ریشه گزارش دوره‌های مختلف را روی هم جمع کرده و بعضی وضعیت‌های قدیمی با
وضعیت امروز ناسازگار بودند. یک index به‌تنهایی این مسئله را حل نمی‌کرد.

## تصمیم

۱. ده پروندهٔ تاریخی در `research/legacy/` ساخته شود؛ گزارش اصلی، manifest،
شواهد کوچک، نوت‌بوک موجود، منبع Git و توضیح نتیجه/ادامه کنار هم قرار بگیرند.
۲. بایت‌های اصل شواهد حفظ شوند؛ جابه‌جایی با inventory و نقشهٔ قدیم/جدید ثبت شود.
۳. تمام فایل‌های کامل محلی در `research/artifacts/legacy/` حفظ شوند. نسخهٔ کوچک
شواهد و نمودارها در Git نگهداری شود و دو ZIP اصلی M0 با هش جدا آرشیو شوند.
۴. پیام‌های قابل مشاهده، قطعه‌های ترمینال، نیازمندی‌های پژوهشگر و پیوست‌های اصلی
در `research/sources/` ثبت شوند. پیام یا تاریخ غایب ساخته نشود.
۵. موارد بازنویسی‌شدهٔ قابل بازیابی از Git احیا شوند؛ مدرک خامی که موجود نیست،
صریحاً مفقود بماند. نسخهٔ کد متناظر با hashها با blobهای Git مشخص شود.
۶. خواندن ورودی‌های قدیمی از مسیر resolver انجام و خروجی جدید ابزارهای قدیمی در
scratch/workspace نوشته شود. نتیجهٔ تازه آرشیو گذشته را بازنویسی نکند.

## گزینه‌ها و دلیل انتخاب

افزودن فهرست بدون انتقال، مشکل پراکندگی را نگه می‌داشت. تبدیل مصنوعی همهٔ گذشته
به protocol/run جدید هم سابقهٔ ازپیش‌ثبت‌شده‌ای را ادعا می‌کرد که وجود نداشت.
پرونده‌های legacy با شواهد اصلی و پیوند به ساختار جدید این دو مشکل را حل می‌کنند.
قواعد آزمایش‌های بعدی همچنان در WORKFLOW برقرارند.

## اثر و معیار پذیرش

هدف ریاضی و دروازه‌های علمی تغییر نمی‌کنند. کد `reference/`، پروتکل و نوت‌بوک
قفل‌شدهٔ WF-E001 و داوری‌های پیشین حفظ می‌شوند. معیار پذیرش، تطبیق هش مهاجرت،
بازیابی منشأ Git، دسترسی به ورودی‌های موردنیاز، اعتبار پیوندها و آزمون مسیرهای
جدید است؛ [گزارش بررسی](../validation/REORGANIZATION_20260920.md).

تفاوت دو PDF مقاله، اشتباه CE در گزارش زمینه‌دار و نبود raw اولیهٔ M2 در پرونده‌ها
ثبت شوند. ادامهٔ علمی همچنان تکمیل تحویل M2 است. این تصمیم، آزمایش یا قبولی تازه
برای مدل ایجاد نمی‌کند.
