# اعتبارسنجی زیرساخت پژوهش — نسخهٔ نخست

تاریخ: ۲۰۲۶-۰۹-۲۰. دامنه: ابزارهای workflow، تولید نوت‌بوک و ورود شواهد؛
آموزش علمی تازه یا اجرای Colab در این اعتبارسنجی انجام نشده است.

## آزمون‌های هدفمند

دو مجموعهٔ `tests/test_research_workflow.py` و `tests/test_colab_workflow.py`
با **۳۶ آزمون موفق** تمام شدند (۲۸ + ۸، مجموع ۹٫۱۹ ثانیه).
موارد پوشش شامل ثبت/اصلاح نسخه، gateهای ناقص یا نامعتبر، نتیجهٔ موفق و ناموفق،
هش و نسخهٔ اشتباه، مسیر ZIP ناامن، شناسهٔ تکراری، عدم بازنویسی شاهد،
داوری دارای ADR، یادآوری کار ناقص، ساخت نوت‌بوک و بازیابی بستهٔ سورس است.
آزمون‌های اتصال runner به importer، نبود ورودی/فرمان و timeout را نیز پوشش دادند.

فرمان اجرای مجدد در ریشهٔ پروژه:

```powershell
python -B -m pytest -q -p no:cacheprovider tests/test_research_workflow.py tests/test_colab_workflow.py
```

در محیط محدود ابزار، دسترسی pytest به پوشهٔ موقت Windows خطای مجوز داشت؛
اجرای آزمون با دسترسی لازم و مسیر موقت جدا موفق شد. این خطا شکست علمی یا شکست assertion نبود.

## کنترل‌های مستقل

- syntax ماژول‌ها، اسکریپت‌ها و تمام سلول‌های کد نوت‌بوک `WF-E001/v001` بررسی شد.
- نوت‌بوک منبع هیچ خروجی ازپیش‌اجراشده ندارد.
- hash مدارک هشت گروه تاریخی با `research/legacy/index.json` تطبیق داده شد.
- اجرای محلی کاملِ نمونه در گام ثبت نتیجه مستند می‌شود؛ از قبولی unit test، اجرای Colab استنباط نمی‌شود.
