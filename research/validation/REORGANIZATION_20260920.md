# سامان‌دهی ریپو و اطلاعات گفتگو — ۲۰ سپتامبر ۲۰۲۶

## نتیجهٔ انتقال

- **۱۰ پروندهٔ تاریخی** برای M0، M1 و هشت مسیر/قرارداد M2 ساخته شد.
- **۱۳۴ فایل اصلی** (۲۸٬۲۷۱٬۲۰۸ بایت) با نقشهٔ مسیر و SHA-256 جابه‌جا شدند.
- **۱۲۱ فایل کوچک و مدرک** در ساختار tracked قرار گرفتند؛ شامل manifestها،
  گزارش‌ها، نوت‌بوک تاریخی M0، log، JUnit، جدول‌ها و نمودارها.
- ۱۰۰ فایل خام اجرای گذشته در `research/artifacts/legacy/` حفظ شدند؛
  فایل‌های بزرگ و نسخهٔ کامل اجرا به Git تحمیل نشده‌اند.
- مقاله، spec اولیه و دو متن پیوست بایت‌به‌بایت حفظ شدند. اطلاعات معنی‌دار گفتگو،
  خطاهای ترمینال، نتایج گزارش‌شده و نیازمندی‌ها با منشأ و سطح اعتبار ثبت شدند.
- دو ZIP اصلی M0 از مسیرهای معرفی‌شده کپی و hash آن‌ها بررسی شد.
- ۱۳ پوشهٔ کشِ خالی حذف و سه پوشهٔ تست ساختگی به `.cache/` منتقل شدند.

## تاریخچه‌ای که دوباره قابل بررسی شد

از Git هفت فایل مهم بازیابی شد: چهار مدرک M0 پیش از GPU، نخستین manifest آزمون
M1 و دو فایل manifest/protocol اجرای اولیهٔ M2. متن گزارش قبلی ریشه و index قبلی
نیز به‌صورت snapshot محفوظ‌اند. ۱۹۵ رکورد path/hash از ۴۰۳ ارجاع تاریخی به کد Git
متصل شدند: ۱۹۴ تطبیق بایت دقیق و یک تطبیق طبق سیاست مستند canonical-LF.
commit پیدا‌شده صرفاً محل بازیابی کد است و زمان اجرا فرض نشده است.

## ناسازگاری‌ها و محدودیت‌های ثبت‌شده

۱. PDF ارسالی با PDF مرجع بایت‌های متفاوت دارد؛ مقایسهٔ علمی نسخه‌ها هنوز انجام نشده.
۲. CE اولیه در گزارش زمینه‌دار از مرحلهٔ قبلی کپی شده؛ مقدار manifest برای این
اجرا `2.477188913445724` است. اصل گزارش حفظ و توضیح در README پرونده درج شد.
۳. raw و checkpointهای M2 اولیه بعداً بازنویسی شده بودند و در Git وجود نداشتند؛
وجود checkpoint زمینه‌دار به‌عنوان بازیابی اجرای اولیه گزارش نشده است.
۴. متن گفتگو، تاریخچهٔ قابل مشاهده و پیوست‌ها را پوشش می‌دهد؛ export کاملِ پیام‌های
غایب یا زمان دقیق همهٔ پیام‌ها در اختیار نبود.
۵. وزن‌ها و ZIPهای حجیم محلی‌اند؛ ثبت locator معادل تأیید وجود نسخهٔ پشتیبان از راه دور نیست.

## سازگاری اجرا و کنترل‌ها

اسکریپت‌های قدیمی، ورودی پذیرفته‌شده را از آرشیو می‌خوانند و خروجی تازه را در
`runs/` یا `research/workspace/` می‌نویسند. ۱۲ آزمون مسیر و یک آزمون بایت‌های مرجع
موفق بودند. checkpoint منتقل‌شدهٔ M0 با hash ممیزی پذیرفته‌شده تطبیق دارد.
ساخت و بازرسی بستهٔ سازگاری M0 نیز انجام شد؛ این بسته scratch است، نه release علمی تازه.

ممیزی نهایی قابل بازتولید از [audit_research_layout.py](../../scripts/audit_research_layout.py)
انجام و در [layout-audit.json](layout-audit.json) ثبت می‌شود. این ممیزی هش تمام
مدارک منتقل‌شده، منابع، تطبیق خروجی با ZIP اولیهٔ Colab، شواهد WF-E001 و پیوندها
را کنترل می‌کند. اصل گزارش‌ها بایت‌به‌بایت حفظ شده‌اند؛ مسیر تاریخی در آن‌ها ممکن
است برای خواندن امروز به `path_map.json` یا README پرونده نیاز داشته باشد.

ادعای اجرای تازهٔ علمی یا عبور M2/M3 ایجاد نشده است. هدف بعدی همچنان تحویل
checkpoint منتخب و آزمون freeze/load/resume در M2 است.
