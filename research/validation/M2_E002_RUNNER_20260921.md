# اعتبارسنجی runner آزمایش M2-E002/v001 — ۲۱ سپتامبر ۲۰۲۶

## دامنه

این گزارش پیاده‌سازی گام ۲ را پیش از انتشار بستهٔ Colab ثبت می‌کند. اجرای مستقیم
محلی برای یافتن خطاهای runner انجام شد و run رسمی واردشده یا تأیید توسعهٔ مستقل نیست.

## اجزای پیاده‌سازی

- `ergt_phi/m2_q_training.py`: انتخاب اولین state واجد streak، checkpointهای کامل،
  freeze و کنترل جلوگیری از update.
- `scripts/m2_q_checkpoint_worker.py`: reload و resume در Python تازه.
- `scripts/run_m2_q_v2.py`: پیش‌گذر raw-only، کنترل shuffled، parity مرجع، گزارش هزینه
  و handoff.
- `research/experiments/M2-E002/v001/`: پروتکل و نوت‌بوک نسخه‌دار.

## مرز نتیجه

این اجرا نشان می‌دهد runner می‌تواند checkpoint قابل تحویل بسازد؛ از آن بهبود پاسخ
native، تعمیم روی cohort تازه، تکمیل همهٔ M2 یا مجوز M3 نتیجه گرفته نمی‌شود. گام بعد
ساخت release قفل‌شده، اجرای Colab و ورود bundle است؛ سپس گام ۳ دادهٔ توسعهٔ تازه را
جداگانه پیش‌ثبت می‌کند.
