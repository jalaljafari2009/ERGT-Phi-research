# LEGACY-M2-INITIAL — کالیبراسیون اولیه و شکست دروازه

این آزمایش anchor مستقل هر توکن را فقط از `Psi0`، طبق معماری اولیهٔ بخش ۵ سند، آموزش داد. ۳۸۲ مثال fit و ۱۲۲ مثال monitor از cohort آموزش مرجع استفاده شد؛ ۲۰ epoch و ۴۸۰ گام optimizer اجرا شد. monitor آزمون مستقل تعمیم مدل اصلی نیست.

## نتیجه

دقت متوازن monitor برابر `0.3386419149975574` بود؛ آستانهٔ `0.70` و recall لازم پاس نشدند. CE از `2.498420084329476` به `1.2966404032886476` رسید، اما کاهش loss برای قبولی کافی نبود. ۹۳ آزمون مهندسی موفق بودند؛ موفقیت آن‌ها شکست کالیبراسیون را تغییر نمی‌دهد.

آزمون تغییر واژهٔ رابطه نشان داد ورودی و anchor دو endpoint ثابت می‌مانند. ۵۵ گروه ویژگی متعارض، شامل ۲۲۴ رویداد، شناسایی شد. این شاهد محدودیت دسترسی اطلاعات در نمایش است؛ عدد سقف حفظ‌کردن ویژگی‌ها حد تعمیم نیست.

منبع بازیابی commit `fd82286b6909cd6aa524c00db92622b63b3af979` است. فایل‌های هم‌نام در `manifests/` و `runs/m2/` بعداً با اجرای زمینه‌دار بازنویسی شدند. curves، feature-conflict JSON و چهار checkpoint اولیه در پوشهٔ اجرای فعلی با hash اصلی مطابق نیستند و هیچ‌وقت در Git ثبت نشده بودند؛ نسخهٔ اصلی آن‌ها از شواهد موجود بازیابی نشده است. پروتکل اصلی از Git قابل بازیابی بود. دو XML مهندسی باقی‌مانده hash یکسان با manifest اصلی دارند و در [پروندهٔ زمینه‌دار](../LEGACY-M2-CONTEXT/evidence/m2/) نگهداری می‌شوند.

نباید checkpointهای زمینه‌دار را به این اجرای اولیه نسبت داد یا برای این run نوت‌بوک ساختگی تولید کرد. تصمیم بعدی، آزمودن زمینهٔ ثابت native در [LEGACY-M2-CONTEXT](../LEGACY-M2-CONTEXT/README.md) بود. این شکست تاریخی همچنان معتبر است.
