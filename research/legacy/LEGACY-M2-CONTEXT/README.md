# LEGACY-M2-CONTEXT — anchor با زمینهٔ native ثابت

این شاخه در پاسخ به [شکست M2 اولیه](../LEGACY-M2-INITIAL/README.md) ساخته شد. ورودی anchor از `Psi0` به `concat(Psi0, stop_gradient(native_final_field))` تغییر کرد؛ این تغییر معماری باید به‌عنوان افزونهٔ سند پایه خوانده شود.

## دو بخش مرتبط

1. ممیزی حساسیت context روی ۸ مثال fit با دو ویرایش رابطه برای هر مثال اجرا شد. هر ۱۶ مشاهده در میدان نهایی حساس بودند؛ مقدار `candidate_pass=true` فقط حساسیت را می‌پذیرد، نه کفایت اطلاعات یا آمادگی مدل.
2. کالیبراسیون با همان split قبلی و ۲۰ epoch اجرا شد. دقت متوازن monitor `0.35229400749063666` بود؛ آستانهٔ ۷۰٪ پاس نشد و M3 بسته ماند. چهار checkpoint موجود مربوط به همین شاخهٔ ناموفق هستند؛ checkpoint پذیرفته‌شدهٔ M2 محسوب نمی‌شوند.

## اختلاف گزارش و داده

جدول گزارش قدیمی CE آغاز monitor را `2.49842` آورده است؛ این مقدار متعلق به M2 اولیه است. مقدار صحیح **این اجرا** در manifest، `2.477188913445724` است. گزارش اصلی برای حفظ سابقه بازنویسی نشده؛ تحلیل جدید باید مقدار manifest را استفاده کند. CE نهایی `1.2991817732502644` است.

ادامهٔ منطقی آن زمان [مقایسهٔ سه نمایش](../LEGACY-M2-DIAGNOSTIC/README.md) بود؛ حساسیت context مشکل آمادگی را به‌تنهایی حل نکرد.
