# LEGACY-M2-INFORMATION — آزمون اطلاعات قابل استخراج از میدان

طبقه‌بند خطی تشخیصی روی ویژگی جفت endpoint اجرا شد تا مشخص شود `Psi0`، میدان نهایی یا تاریخچهٔ چهار snapshot چه اطلاعاتی دربارهٔ رابطه دارند. این طبقه‌بند وارد پاسخ native نشد. همان ۳۸۲ fit و ۱۲۲ monitor قبلی و ۴۰ epoch استفاده شدند.

| ویژگی | دقت متوازن واقعی | برچسب درهم‌ریخته |
|---|---:|---:|
| `Psi0` | ۰٫۳۲۳۰۹۲ | ۰٫۳۵۵۳۰۹ |
| میدان نهایی native | ۰٫۴۱۴۱۶۰ | ۰٫۳۳۳۳۳۳ |
| تاریخچهٔ میدان | ۰٫۴۲۳۰۹۶ | ۰٫۲۹۴۰۱۷ |

زمینه اطلاعات قابل استخراج بیشتری داشت، ولی هیچ گزینه‌ای آستانهٔ ۷۰٪ را پاس نکرد. این یک مشاهدهٔ اکتشافی تک‌تقسیم است؛ از آن نمی‌توان بهبود پاسخ نهایی یا برتری آماری مستقل نتیجه گرفت.
