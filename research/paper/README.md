# مدارک آماده‌سازی مقاله

| فایل | محتوای قابل استفاده |
|---|---|
| [CLAIMS](../CLAIMS.md) | ادعای مجاز، شاهد مستقیم و محدودیت علمی |
| [LEGACY_CATALOG](LEGACY_CATALOG.md) | تمام پرونده‌های تاریخی، مسیرهای منفی و نسخه‌های اصلاح‌شده |
| [legacy_evidence.csv](legacy_evidence.csv) | مقادیر ثبت‌شدهٔ تاریخی با JSON pointer و hash منبع |
| [RUN_CATALOG](RUN_CATALOG.md) | اجراهای دارای قرارداد جدید، داوری و بررسی اعتبار فعلی |
| [evidence.csv](evidence.csv) | مقادیر gateهای اجراهای نسخه‌دار |
| [منابع مقاله و گفتگو](../sources/README.md) | منشأ PDFها، spec و نتایج تحویل‌شده |

تولید دوباره از ریشهٔ ریپو:

```powershell
python -B scripts/index_research_history.py
python -B scripts/export_research_catalog.py
```

CSV تاریخی مقادیر اصلی را حفظ می‌کند و نوع شاهد را مشخص می‌کند؛ از روی آن
تأیید مستقل، خطای استاندارد یا بهبود پاسخ نهایی اختراع نمی‌شود. برای نمودار مقاله،
روش تجمیع، seedها، کنترل‌ها و تاریخچهٔ استفاده از داده باید کنار جدول ثبت شوند.
اعداد monitor توسعه و آزمون نهایی مستقل در یک ستون نتیجهٔ تأییدی ادغام نشوند.
